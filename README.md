# Speaker AI
### Inteligência artificial aplicada à aprendizagem de idiomas

A **Speaker AI** é uma aplicação desenvolvida em Python que utiliza inteligência artificial para proporcionar uma experiência interativa de aprendizagem da língua inglesa.

O projeto busca aproximar a tecnologia do ensino de idiomas, oferecendo aos estudantes um ambiente para praticar inglês, interagir com um tutor inteligente e desenvolver suas habilidades de comunicação.

## Funcionalidades

- **Conversação com IA:** interação em inglês com um tutor inteligente.
- **Prática de áudio:** recursos de interação e aprendizagem por áudio.
- **Correção de erros:** auxílio na identificação e correção de construções linguísticas.
- **Autenticação de usuários:** acesso integrado com conta Google.
- **Experiência interativa:** interface desenvolvida para facilitar a prática contínua do idioma.

## Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|
| Python | Linguagem principal |
| Streamlit | Interface da aplicação |
| Groq API | Integração com inteligência artificial |
| Supabase | Serviços de autenticação e infraestrutura |
| Google OAuth | Autenticação de usuários |

## Objetivo do projeto

Desenvolver uma ferramenta que complemente o ensino tradicional de inglês, permitindo que estudantes tenham mais oportunidades de praticar o idioma e interagir com inteligência artificial fora do ambiente convencional de sala de aula.

A proposta combina conhecimentos de programação, integração de APIs e experiência pedagógica na construção de uma solução tecnológica voltada à educação.
